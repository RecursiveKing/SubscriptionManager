# Менеджер подписок и регулярных платежей (SubscriptionManager)

Настольное приложение на C++ (Qt 6) для учёта регулярных платежей, контроля дат списаний и анализа расходов в белорусских рублях (BYN).

## Основной функционал
- [x] Локальное хранение данных в SQLite (таблицы подписок и истории платежей)
- [x] Расчёт стоимости подписок в пересчёте на месяц и год
- [x] Добавление, редактирование и удаление подписок
- [x] Отметка платежа как оплаченного с автоматическим переносом даты списания
- [x] Поиск, фильтрация по категориям и подсветка ближайших списаний
- [x] Аналитика расходов по категориям (круговая диаграмма QtCharts)
- [x] Экспорт данных в CSV

## Технологии
- **Язык:** C++17
- **GUI и модули:** Qt 6 (`QtWidgets`, `QtSql`, `QtCharts`)
- **База данных:** SQLite 3
- **Сборка:** CMake + Ninja

## Структура проекта
- `src/models/` — модели данных и бизнес-логика расчёта периодов и сумм
- `src/database/` — слой работы с SQLite (инициализация таблиц, CRUD, транзакции)
- `src/ui/` — графический интерфейс приложения
